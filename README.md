# WordMark-4-PotPlayer

영상 단어 책갈피 생성기입니다. PotPlayer 공식 앱이 아닌 비공식 도구입니다.

영상의 음성을 인식해서, 지정한 단어가 나오는 위치마다 팟플레이어 책갈피를 만듭니다.
결과는 영상과 같은 폴더에 `영상이름.pbf` 숨김 파일로 저장되므로 탐색기에는 영상만 보이고, 팟플레이어로 영상을 열면 책갈피 목록에 나타납니다.

## 다운로드해서 사용 (일반 사용자)
Python 없이 쓰려면 [Releases](../../releases) 페이지에서 최신 파일을 내려받아 압축을 풀고 `WordMark-4-PotPlayer.exe`를 실행하세요.

- Windows 64비트용이며 팟플레이어가 설치되어 있어야 합니다.
- CPU로 동작하고 기본 모델은 `small`입니다. 첫 실행 때 모델을 내려받으므로 인터넷이 필요합니다.
- 코드 서명이 없어서 Windows 보안 경고가 뜰 수 있습니다. 이때는 **추가 정보 → 실행**을 누르세요.

## 소스에서 실행 (개발자, GPU 사용)
```
pip install -r requirements.txt
```
처음 실행할 때 Whisper 모델을 내려받습니다 (large-v3는 약 3GB).

## 실행
- **GUI**: `.exe` 실행, 또는 소스에서는 `run.bat` 더블클릭 (`python video_bookmarker.py`)
  1. 파일 또는 폴더 추가 (폴더는 하위 폴더까지 검색)
  2. 찾을 단어를 쉼표로 구분해 입력 (예: `사과, 공원`)
  3. 단어 언어 선택: 한국어 / English / 日本語
  4. 시작
- **CLI**:
  ```
  python video_bookmarker.py "D:\Videos" -w "사과,공원" -l ko
  python video_bookmarker.py movie.mp4 -w "arigatou,sugoi" -l ja
  python video_bookmarker.py talk.mkv -w "hello,machine learning" -l en --replace
  ```

## 옵션
| 옵션 | 설명 |
|---|---|
| 모델 | `large-v3`(정확·기본), `large-v3-turbo`(빠름), `medium`, `small`(CPU용) |
| 장치 | `auto`: GPU를 쓸 수 있으면 GPU, 아니면 CPU |
| 앞당김(초) | 단어보다 몇 초 앞에 책갈피를 둘지 (기본 1초) |
| 중복 병합(초) | 같은 단어가 이 시간 안에 반복되면 책갈피 하나로 합침 (기본 0 = 합치지 않음). 이 설정과 별개로, 1초 안에 몰린 책갈피는 단어가 달라도 가장 빠른 것 하나만 남김 (직접 만든 책갈피는 유지) |
| 덮어쓰기 | 끄면 기존 `.pbf` 책갈피를 유지하고 추가만 함. |
| 인식 텍스트 저장 | 인식된 모든 단어와 시간을 `.transcript.txt`로 저장 (단어가 안 잡힐 때 확인용) |

## 영상 끝까지 검사
음성 인식은 먼저 VAD로 말소리 구간만 빠르게 처리합니다. 그 뒤 단어가 하나도 잡히지 않은 구간(8초 이상 빈 곳, 그리고 마지막 단어 이후부터 영상 끝까지)을 VAD 없이 한 번 더 인식합니다.
그래서 배경음악에 묻히거나 끝부분에 작게 말한 단어도 찾고, 영상 맨 끝까지 확인한 뒤에 검사를 끝냅니다. 로그에 `영상 끝까지 검사 완료`가 표시됩니다.

## 언어별 단어 검색 방식
- **한국어**: 띄어쓰기와 조사를 무시합니다. `사과`로 검색하면 "사과를", "사과가"도 찾습니다.
- **영어**: 단어 단위로 찾고 대소문자는 무시합니다. `cat`으로 검색하면 "cats"는 찾지만 "category"는 찾지 않습니다. 여러 단어로 된 구절도 됩니다.
- **일본어**: 가나, 한자, 로마자 모두 입력할 수 있습니다.
  - 로마자 표기가 달라도 같은 단어로 봅니다: `toukyou` = `tokyo` = `tōkyō`, `shi`/`si`, `tsu`/`tu`, `chi`/`ti`, `fu`/`hu`, `ji`/`zi`
  - 장음과 촉음을 빠뜨려도 됩니다: `raamen` = `ramen`, `kitte` ≈ `kite`
  - 인식된 문장의 한자 읽기는 SudachiPy로 구합니다. 한자 읽기가 애매한 단어는 가나로도 검색해 보세요.

## 기존 책갈피가 지워지지 않을 때
팟플레이어가 책갈피를 내부 설정(레지스트리)에 저장하는 환경에서는, 영상을 한 번 재생하면 `.pbf` 내용이 내부 설정으로 복사됩니다. 이후 `.pbf`를 다시 만들면 팟플레이어는 새 책갈피를 추가만 하고 기존 책갈피는 지우지 않습니다. 필요 없는 책갈피는 팟플레이어의 책갈피 편집 메뉴에서 지워 주세요.

## 팟플레이어에서 책갈피가 안 보일 때
환경설정(F5) → 재생 → 책갈피 항목에서 **책갈피를 .pbf 파일로 저장/불러오기**가 켜져 있는지 확인하세요.
책갈피 목록은 영상 재생 중 마우스 오른쪽 메뉴 → 책갈피에서 볼 수 있습니다.
