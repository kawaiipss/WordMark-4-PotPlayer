# WordMark-4-PotPlayer

영상에서 지정한 단어가 나오는 위치에 팟플레이어 책갈피를 자동으로 만들어 주는 Windows 프로그램입니다.
한국어, 영어, 일본어를 지원합니다. PotPlayer 공식 앱이 아닌 비공식 도구입니다.

## 다운로드
[Releases](../../releases) 페이지에서 최신 zip 파일을 내려받으세요.

## 사용 방법
1. zip 파일의 압축을 풉니다.
2. `WordMark-4-PotPlayer.exe`를 실행합니다.
3. 영상이나 폴더를 고르고, 찾을 단어와 언어를 입력한 뒤 시작합니다.
4. 처리가 끝나면 팟플레이어로 영상을 열고, 마우스 오른쪽 메뉴의 책갈피에서 확인합니다.

책갈피 파일(`영상이름.pbf`)은 영상과 같은 폴더에 숨김 파일로 저장되므로 탐색기에는 영상만 보입니다.
영상을 다른 곳으로 옮기면 책갈피가 따라가지 않을 수 있습니다.

## 알아두기
- Windows 64비트용이며, 팟플레이어가 설치되어 있어야 합니다.
- 첫 실행 때 음성 인식 모델을 내려받습니다. 인터넷 연결이 필요하고, 모델 크기에 따라 시간이 걸립니다.
- CPU로 동작합니다. 모델이 클수록 정확하지만 느립니다. 기본값은 `small`입니다.
- 코드 서명이 없어서 Windows 보안 경고가 뜰 수 있습니다. 이때는 **추가 정보 → 실행**을 누르세요.

## 책갈피가 안 보일 때
환경설정(F5) → 재생 → 책갈피 항목에서 **책갈피를 .pbf 파일로 저장/불러오기**가 켜져 있는지 확인하세요.

## 기존 책갈피가 지워지지 않을 때
팟플레이어가 책갈피를 내부 설정에 저장하는 환경에서는, 영상을 한 번 재생하면 책갈피가 내부 설정으로 복사됩니다.
이후 다시 처리해도 기존 책갈피는 지워지지 않습니다. 필요 없는 책갈피는 팟플레이어의 책갈피 편집 메뉴에서 지워 주세요.
